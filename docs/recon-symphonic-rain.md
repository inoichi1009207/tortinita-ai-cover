# 交响乐之雨 游戏资源侦察报告(只读,2026-08-31;v2=经 codex 外审修订)

目标:评估从本地合法持有的游戏目录提取「朵鲁妲(トルティニタ)语音 + 演唱」用于个人
非商用 AI 翻唱训练的可行性。本批只侦察,零写入游戏目录,未提取任何资源。
**v2 修订**:v1 的 4 处断言被 codex 外审证伪/降档,已在正文改正,处置见尾节。

## 结论一行

**可提取性:高。** 封包=工画堂 HyPack v3,语音为明文 MS-ADPCM WAV 直存(8,603 条,零压缩、
尺寸全配),GARbro 官方支持本作;「语音→角色」映射走 SCRIPT.PAK 内 KGO 脚本(Cocotte 压缩,
GARbro 有解码器,Switch 社区有带 `Voice` 指令的 KGO 反汇编器可参照)。

## HyPack v3 头部格式(v2 勘误)

`HyPack`(6B)+ 版本 u16(0x0300/0x0301)+ **索引位移** u32 + 条目数 u32。
⚠️ **索引地址 = 0x10 + u32@0x08**(相对数据基址,不是绝对地址——v1 公式漏了 +0x10,
直接跳过去会先读到 16 个零字节;GARbro 源码同式)。

## 提取路线(未执行,列给下一批)

1. **首选 GARbro**:官方支持表逐字列出 `*.pak | HyPack | Kogado | …Symphonic Rain`;
   源码支持 v3.00/3.01、Cocotte 解压、WAV 与 ADP。F4 批量导出。
2. **备选自写解包**:按上节格式(带 +0x10 修正);RIFF 签名扫描只作损坏恢复兜底,
   正常提取按索引走(裸扫有数据区偶然命中风险)。
3. **角色归属**(硬点,更新后的三路):
   a. GARbro/Cocotte 解出 KGO,参照 [SymphonicRain-ENX](https://github.com/masagrator/SymphonicRain-ENX)
      的 `kgo_commands.py`(含 `Voice` 指令定义)解说话人标签——**注意它基于 Switch/Steam 版,
      本地是 2010 版,先拿 1 个场景交叉对齐再放量**;
   b. 按场景包归属粗筛 + 人工抽听;
   c. ⚠️ 说话人聚类(pyannote 类)有硬上限:**Steam 官方配音表载明 Arietta 与 Tortinita
      同为中原麻衣配音**——聚类只能圈出「中原麻衣簇」,分不开这两个角色,最终仍需
      KGO 标签或剧情上下文。
4. SONG.ADP:GARbro 转码 → 声学检测(有无人声)→ 确认哪几首是朵朵演唱。
