# 宿主软件补录施工单(目标:"as we weave memory" 整句,约 6 秒)

## 装两样(都免费)

1. **Synthesizer V Studio Basic**(编辑器):https://dreamtonics.com/synthesizerv/ → Basic 版下载
2. **Eleanor Forte Lite**(免费英文声库):同站 Voice Database 区,装进 SV 即可

## 操作(预计 15–20 分钟)

1. 新建工程;把参考音频拖进去当底(文件:`clipboard/ai-cover/lead_win_kara2.wav`,
   就是那句的原唱,你听着它对音);
2. 钢琴卷帘里点音符+填词:整句 `as we weave memory`(词可整句输入让它自动分配);
   起手两个音机器已扒出:**wea=B4、-ve=D5**,后面的跟耳朵走,音高不确定就上下挪着试听;
3. 节奏对齐参考音频(粗对即可,±0.1 秒内我后期能滑);
4. 唱法参数不用动(音色反正会换成朵朵);
5. 导出:**WAV,44100Hz**,命名 `sv_weave_memory.wav`,放到 `D:\test\clipboard\ai-cover\`。

## 你导出后我接手

转换成朵朵(输入是合成声,饱满干净,追踪器零压力)→ 按时间轴缝进主唱 → 终版。

> 附:若 SV 装不上/懒得装,备选是 OpenUtau+DiffSinger 英文库(也免费,界面糙些);
> 或者你就哼这 6 秒录下来,效果等价。
